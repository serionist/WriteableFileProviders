# Modernization roadmap and feature list, 2026-10-10

What #3 should deliver and in what order. It draws on three inputs:

- the codebase review, [2026-10-10-codebase.md](2026-10-10-codebase.md), with findings F1–F77;
- research into what each storage service and SDK can do, checked against vendor docs and nuget.org on 2026-10-10;
- research into current .NET library practice.

Claims marked *(verify)* were not confirmed against a primary source. Each must be checked before a plan relies on it.

## Where the code stands

- **It works on the happy path**, but the review found 32 major problems:
  - an escape from the root on S3 (F1, F2);
  - lost or half-written data when a write fails (F3–F6, F8);
  - seven providers that disagree on what move, overwrite, a missing file, folder info, download URL lifetime and
    `PhysicalPath` mean (F11, F18–F21).
- **The stack is dated:**
  - net8.0, out of support on 2026-11-10;
  - AWS SDK v3, out of support since 2026-06-01;
  - Box.V2.Core five majors behind;
  - deprecated Azure.Identity, and a deprecated, unlisted Graph.Core pin;
  - MSTest 3.6 on VSTest.
- **Missing APIs:** no `CancellationToken`, no ranged read.
- **Reads:** four providers download the whole object to a temp file on every read.
- **Coverage** is configured nowhere. The one measured figure, from a single test class, is 13% overall.
- **What sets the library apart**, and what to keep:
  - it is a drop-in `IFileProvider`;
  - it covers Box and SharePoint;
  - providers are built from configuration by `Type`;
  - root scoping with path-segment validation.

  FluentStorage, ManagedCode.Storage and SharpGrip.FileSystem have none of these. FluentStorage already has ranged reads
  and upload URLs, the two main features this library lacks.

## Feature list

Cost: S is up to 3 days, M is 1–2 weeks, L is more than 2 weeks. "Native" means the service does it, so the library
only wraps it.

### P1

1. **Index-based reads**: byte ranges and seekable streams on all seven providers (M).
   - `ReadRangeAsync(path, offset, length)` returns a stream of just that slice.
   - `OpenReadSeekableAsync(path)` returns a read-only stream with `CanSeek` and `Length`, which fetches ranges as you
     seek.
   - Native ranges on every service:
     - Azure `OpenReadAsync`, already seekable;
     - S3 `ByteRange`;
     - MinIO `WithOffsetAndLength`;
     - GCS `Range`;
     - Box `Range`;
     - Graph `Range` on the download URL, which may ignore it, so the code must handle that;
     - Physical `RandomAccess`.
   - The other five providers get a seekable stream from one Common `RangeReadStream` over their range calls.
   - Every provider pins the object version (ETag or generation) while it reads, so a file that changes mid-read throws
     rather than mixing two versions.
   - It also ends the full temp-file download on MinIO, GCS, Box and SharePoint (F63).
2. **Signed URLs for download and upload on all seven providers** (M–L).
   - One call, `GetSignedUrlAsync(path, options)`.
     - Options: validity, permission (read, create, write), download file name, content type, maximum upload size.
     - It returns the URL, the HTTP method, the true expiry, any required headers, and its kind: signed,
       pre-authenticated, sharing link or gateway.
     - A provider that cannot honour an option throws and says why. It never shortens the validity silently, unless the
       caller allows it.
   - **Azure:** service SAS, plus user delegation SAS once Entra credentials are supported (up to 7 days). Upload uses a
     SAS with create or write.
   - **S3:** presigned GET and PUT, plus presigned POST, which can cap the upload size. Up to 7 days, or less with
     temporary credentials.
   - **MinIO:** presigned GET, PUT and POST, up to 7 days. This also fixes F45.
   - **GCS:** V4 signed GET and PUT, a POST policy, and a signed start of a resumable upload. Up to 7 days.
   - **Box, SharePoint and Physical:** through the gateway below by default.
     - Box's download URL lasts 15 minutes and Graph's about an hour, and neither can be changed.
     - Their sharing links take an expiry, but they create state on the item: Box allows only one shared link per item,
       and expiry needs a paid plan. Graph returns an existing link of the same type, and tenant policy can block it.
     - Sharing links are therefore only an explicit opt-in.
     - Uploads: Graph's `createUploadSession` returns a pre-authenticated upload URL, and Box offers a downscoped token.
   - **New package `WriteableFileProviders.AspNetCore`**, a gateway.
     - `MapWriteableFileProviderUrls("/f")` serves GET, HEAD and PUT for tokens that the app issues.
     - Tokens are ASP.NET Core Data Protection time-limited payloads. They are encrypted, they rotate their keys, and
       they bind provider, path and permission.
     - It serves HTTP ranges through the seekable stream from item 1.
     - Safeguards:
       - the path comes only from the token and is checked again on use;
       - files are served as attachments with `nosniff` and `no-referrer`;
       - upload tokens can be made one-time;
       - uploads are capped in size.
     - Physical needs it; Box and SharePoint use it whenever a caller-set lifetime matters.
   - `GetDownloadUrl` stays, with each provider's behaviour documented. Changing what it means would be a door.
3. **Cancellation everywhere** (S on new members, M at the major). Every SDK supports it, but no member takes a token
   (F16).
4. **Dependencies brought current** (M; Box alone about 1 week).

   | Package | From | To |
   |---|---|---|
   | AWSSDK.S3 | v3 | v4 |
   | Box.V2.Core | 5 | 10 (generated SDK, a rewrite of the provider) |
   | Microsoft.Graph / Graph.Core | 5 / 3.2.6 | 6 / 4 |
   | Google.Cloud.Storage.V1 | 4.15 | 5 |
   | Azure.Storage.Blobs | 12.23 | 12.30 |
   | Azure.Identity | deprecated pins | 1.21, and dropped from AzureBlob, which never uses it |
   | Microsoft.Extensions.* | 8.x | 10.x |

### P2

5. **Streaming writes** with `OpenWriteAsync`, skipping the temp-file round trip.
   - Native on Physical, Azure, S3 and GCS.
   - Box and Graph spool only when the length is unknown.
   - S3 multipart above 5 GB (F65).
6. **ETags and conditional writes:** an ETag or version on file info, plus `IfMatch` and `IfNoneMatch: *` (create
   only). Native on six providers.
7. **Content type and metadata** on write and read, ending the hard-coded `application/octet-stream`.
8. **Async listing:** `EnumerateAsync(path, recursive, ct)` as `IAsyncEnumerable`, paging natively.
9. **Dependency injection:**
   - `AddWriteableFileProvider("name", configSection)` as keyed singletons, through the existing serializer.
   - Constructors that take a prebuilt SDK client, for managed identity, Aspire and custom retries.
10. **More credential options**, all additive configuration properties:
    - Azure `TokenCredential` and managed identity (which enables user delegation SAS);
    - the S3 default credential chain, plus `ServiceUrl` and `ForcePathStyle` (needed for R2, Wasabi, MinIO and the
      emulators);
    - SharePoint certificate or managed identity.
11. **Server-side copy:** `CopyAsync` on every provider. Native GCS `MoveObject` for an atomic move.
12. **Physical `Watch`**, delegated to `PhysicalFilesWatcher`. Every provider throws today.

### P3

13. **Change notifications for the object stores:** a polling `IChangeToken`, MinIO bucket listen, Graph `delta`.
14. **`IProgress<long>`** for uploads and downloads.
15. **OpenTelemetry:** an `ActivitySource` and a `Meter` named `WriteableFileProviders`, with no paths in spans by
    default. `ILogger` takes over from today's swallowed exceptions, with secrets never logged.
16. **Health checks** in the AspNetCore package.
17. **Trimming and native AOT** for Common and Physical, once the serializer is annotated or a source-generated path
    exists.

## Engineering work

This is not features. It is what makes the repo modern and keeps it that way.

- **Solution:**
  - `.slnx`;
  - `src/` and `tests/`, each with its own `Directory.Build.props`;
  - central package management with lock files;
  - unused packages dropped (F72).
- **Strictness:**
  - nullable;
  - warnings as errors;
  - code style enforced in the build;
  - `AnalysisLevel` latest-recommended;
  - XML docs on every public member (F59–F61);
  - Public API analyzer files and package validation, so every API change shows in a PR diff.
- **Packaging:**
  - MinVer;
  - SourceLink, built into the SDK;
  - snupkg symbols;
  - a README per package, plus an icon and tags (F76).
- **Tests:**
  - MSTest 4.5 on Microsoft.Testing.Platform.
  - Testcontainers: Azurite; adobe/s3mock for S3 and MinIO (no MinIO server image exists any more); fake-gcs-server
    for GCS.
  - WireMock for Box and SharePoint, so neither needs an account. An `HttpMessageHandler` seam per provider for fault
    injection.
  - Live suites run only when a `[LiveCloud]` condition is met, not through a class-name filter.
  - Settings come from environment variables and user-secrets, and the build no longer needs `testsettings.json`.
  - A golden corpus that pins the configuration shape (F30).
  - The cross-provider contract from D4 lives in `TestBase` (F57).
  - Every run cleans up after itself (F29).
- **Coverage:**
  - Microsoft's coverage extension.
  - A gate run as a file-based app (`eng/coverage-gate.cs`) that fails when an assembly drops below its floor.
  - Floors start at the measured figures and rise to **90% of lines on every assembly**.
- **CI:**
  - `ci.yml`: build, offline and emulator tests, coverage gate and pack on Ubuntu; unit and Physical tests on Windows.
  - A nightly live suite on `main`, never on PRs from forks.
  - CodeQL and Dependabot.
  - Releases on a tag, with nuget.org trusted publishing behind a maintainer approval.
  - CI as a required check closes the "outside PRs merge on a read-only review" gap in REVIEW.md.
- **Launch:**
  - LICENSE (D8), README, CONTRIBUTING, SECURITY with private vulnerability reporting.
  - Reserve the `WriteableFileProviders.` id prefix on nuget.org.
  - Unlist the 2018–2024 versions.
